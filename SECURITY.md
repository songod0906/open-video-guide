# Security Policy

## Supported versions

The project is in pre-alpha development.
Security fixes apply to the default branch until the first release.

## Report a vulnerability

Use the private GitHub security advisory function for this repository.
Do not put exploit details in a public issue.

Include:

- The affected version or commit
- The affected component
- The reproduction steps
- The possible effect
- A proposed control when available

The project owner will confirm receipt.
The project will coordinate disclosure after a verified fix.

## Deployment warning

Do not expose the pre-alpha service to the public internet.
Keep local endpoints on the loopback interface.

Do not use private or regulated video during early development.
Read `docs/SECURITY_PRIVACY.md` before you add remote access.
