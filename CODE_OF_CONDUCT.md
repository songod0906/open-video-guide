# Code of Conduct

## Expected conduct

Treat each person with respect.
Give technical feedback about the work, not the person.

Use clear and inclusive language.
Accept a correction when evidence shows an error.

Do not publish private information.
Do not use harassment, threats, or discriminatory language.

## Enforcement

Report conduct problems privately to the project owner.
Do not put sensitive evidence in a public issue.

The project owner will review the report.
The project owner can remove content or restrict participation.

The response will depend on the severity and the available evidence.
An urgent safety risk can require an immediate restriction.
