# Project Governance

## Current model

The project uses a maintainer-led model during pre-alpha development.
The repository owner is the initial maintainer and product owner.

## Decision authority

The product owner controls scope and release acceptance.
The technical lead controls architecture after documented review.

The security reviewer can stop a release for a critical security risk.
The release manager can stop a release when evidence is incomplete.

One person can have several roles.
The release record must show each approval role.

## Technical decisions

Use an architecture decision record for a hard-to-reverse decision.
Discuss the proposal in a public issue when no security limit applies.

## Maintainers

A contributor can become a maintainer after sustained and trusted work.
Current maintainers decide each invitation.

The project will update this model before version 1.0.
