# Project Terminology

This list defines project-specific technical terms.
Use one term for one meaning.

| Term | Approved meaning |
|---|---|
| adapter | Code that connects one external system to the application service |
| artifact | A file that a job creates or uses |
| candidate frame | A frame selected for later analysis |
| confidence | A calibrated value from zero to one |
| core engine | Platform-independent media and guide logic |
| evidence | A timestamped source record that supports a step |
| guide | An ordered set of illustrated tutorial steps |
| job | One controlled guide-generation operation |
| manifest | A record of versions, settings, and artifacts |
| Model Context Protocol | An open protocol that connects AI clients to tools and data |
| model profile | A tested set of models and runtime settings |
| optical character recognition | Extraction of visible text from an image |
| renderer | Code that writes an output format from a guide |
| review state | The recorded user-review status of a step |
| schema | A machine-readable data contract |
| step | One user action with time bounds and evidence |
| verifier | Code that tests a proposed step against evidence |
