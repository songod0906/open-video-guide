# ADR-0003: Use Apache License 2.0

Status: Accepted

Date: 2026-07-31

## Context

The project needs a permissive open-source license.
The license must permit commercial and noncommercial use.

## Decision

Project source will use Apache License 2.0.
Third-party components and model files keep their own licenses.

## Consequences

Users receive broad use rights and an explicit patent grant.
Contributors and distributors must keep the required notices.

The project must review every component license.
An Apache repository license does not replace that review.
